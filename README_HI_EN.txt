IDV Calculator Android Project
==============================

Features
- Hindi / English toggle
- Two-wheeler, private car and commercial vehicle category selector
- Listed price, completed vehicle age in months and separate accessories input
- Traditional age-wise depreciation estimate up to 5 years
- More than 5 years: accepts mutually agreed IDV rather than inventing a standard percentage
- Commercial vehicle warning to verify insurer-specific rules

Open in Android Studio
1. Extract this ZIP.
2. Android Studio > Open > select the extracted IDVCalculator folder.
3. Allow Gradle sync and install the required Android SDK (compileSdk 35).
4. Connect an Android phone with USB debugging enabled, or start an emulator.
5. Press Run.

To build an APK:
Build > Build Bundle(s) / APK(s) > Build APK(s).
The APK is usually generated under app/build/outputs/apk/debug/.

Important
This is a starter Android Studio source project, not a signed Play Store release APK.
The calculator is an indicative estimator using the traditional private-motor age slabs.
Actual IDV must be checked against the insurer's current product wording and quote.
Commercial motor products may have different provisions. Five-year-plus vehicles
require valuation / mutual agreement. Do not use this tool as a binding quote.
